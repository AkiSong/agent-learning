## 技术摘要

该项目是一个 Claude Code 的 AI 设计工具集成方案，支持将 Figma 设计直接转换为代码。项目提供 React 19 和 Tailwind v4 支持，包含 Model Context Protocol (MCP) 服务器设置、设计系统自动化和 UI/UX 原型生成等功能。它作为 Anthropic 设计工具的研究预览版本，旨在打通设计到开发的自动化工作流。

## 趋势分析

设计到代码（Design-to-Code）的自动化是 AI 应用的重要前沿，Claude 生态的快速扩展推动了相关工具链的繁荣。MCP 协议的集成使得 AI 代理能够深度参与设计系统构建，预计此类工具将显著提升前端开发效率。
