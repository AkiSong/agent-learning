## 技术摘要

ZeroClaw Plugin Hub 是一个面向 Claude Code 的多 MCP 路由器和 SDK 工具包。项目提供了 Agentic CLI 的扩展架构，支持多个 Model Context Protocol 服务器的动态路由和集成。它帮助开发者构建可扩展的 Claude Code 工作流，实现不同 MCP 服务之间的协调调用，增强 AI 代理的工具链组织能力。
